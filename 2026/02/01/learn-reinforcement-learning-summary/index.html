强化学习—方法梳理（Reinforcement Learning — Methods Overview）

发布于：2026-02-01

  • 目标：针对MDP问题求解最优策略，写为Bellman最优公式\(\begin{align} v=\max_\pi(r_\pi+P_\pi v),\ \forall s\in\mathcal{S} \end{align}\)

  • 其求解思路总体分为两部分：

    • 策略评估：计算Action对应的Action Value\(q(s,a)\)

    • 策略改进：根据Action Value调整策略\(\pi\)

方法 策略评估 策略改进
策略迭代（有模型） \(q_\pi(s,a)=\sum_r p(r|s,a)r+\sum_{s'} p(s'|s,a)\sum_{a'} \pi(a'|s')q_\pi (s',a')\)
不动点法求解，但是变量过多，因此先通过Bellman方程计算中间变量State Value，再计算Action Value
注：不动点法可以设置迭代次数人为截断，提高速度		 \(\pi(a|s)=\max_a q_\pi(s,a)\)
选择最大的Action Value作为策略
蒙特卡罗法（无模型） p未知，对每个\((s,a)\)采样m个episodes，每个episode包含n个时间步，估计Action Value 同上
时序差分法（Sarsa） 蒙特卡罗法每次policy更新后需要重新大量采样计算，历史数据没有复用。随机近似提供了一种利用历史数据的方法：
\(\omega^\ast=\mathbb{E}_\pi[X]<br>\\<br>\omega_{k+1}=\omega_k-\alpha_k(\omega_k-x_k),\ x_k\sim \pi(x)<br>\\<br>\omega_{k+1} \to \omega_\ast,\ when\ k\to \infin\)
因此:
\(q_\pi (s,a)=\mathbb{E} [R+q_\pi (S',A')]<br>\\<br>q_{k+1}(s_t, a_t) = q_k(s_t, a_t) - \alpha_k [q_k(s_t, a_t) - [r_{t+1} + q_k(s_{t+1}, a_{t+1})]], <br>\\<br>q_{k+1}(s, a) = q_k(s, a), \quad \forall (s, a) \neq (s_t, a_t)\)		 同上
Q-learning Sarsa算法是先估计策略\(\pi\)下的Action Value，再策略改进，每次迭代需要重新采样（每次策略采样之间串行工作），交替进行，效率低。Q-learning直接估计最优策略对应的Action Value，一方面提高收敛速度，另一方面实现Off-policy训练（\(S'\)的分布与策略无关），策略改进过程中不需要重新采样（允许并行批量采样）。根据Bellman最优公式写Action Value的期望形式：
\(q(s,a)=\mathbb{E} [R+\max_{a'} q (S',a')]<br>\\<br>q_{k+1}(s_t, a_t) = q_k(s_t, a_t) - \alpha_k [q_k(s_t, a_t) - [r_{t+1} + \max_{a'} q_k(s_{t+1}, a')]], <br>\\<br>q_{k+1}(s, a) = q_k(s, a), \quad \forall (s, a) \neq (s_t, a_t)\)		 同上，但是策略评估和策略改进不再需要交替进行，可以最优策略评估完成后再改进
Deep Q-learning 表格形式的Action Value无法解决状态\(S\)或者动作\(A\)任意一者变为连续的问题（表格之外无法找到对应的Action Value），因此Action Value调整为函数形式。采用随机梯度下降来估计函数形式的Action Value：
\(J(\omega)=\mathbb{E} [(q(S,\omega)-R-\max_{a'} q (S',a'))^2]<br>\\<br>\omega_{k+1} = \omega_k - \alpha_k [q(s_t, a_t,\omega_k) - [r_{t+1} + \max_{a'} q(s_{t+1}, a',\omega_k)]]\nabla_\omega q(s_t,a_t,\omega_k)\)
相比于Off-policy版本的Q-learning，DQL的action value是联动的，因此期望形式中增加了一个随机变量S。若假设S均匀分布，对于训练数据需要打散后重新采样；若假设S策略分布，则DQL转变为On-policy方法。
Sarsa以及Q-learning在计算过程中都用\(q_k\)取代了期望公式中的\(q_\pi\)，因此策略估计为有偏估计，且偏置动态变化影响收敛。对此，Deep Q-learning提出目标网络和训练网络，即在一定迭代次数中\(q_\pi\)采用固定\(q_k\)（目标网络），延迟学习。		 \(a=\max_{a} q(s, a,\omega)\)
与表格形式的Action Value不同：
对于离散Action，需要将每个Action代入寻找最优解
对于连续Action，需要解最优化问题

=Actor-Critic		 同上 DQL等算法求得Action Value后再通过最优化得到Action，效率低。因此策略梯度直接同时优化策略函数\(\pi(\theta):S\to A\)。根据随机梯度下降得到：
定义指标\(J=\sum_{s\in S}d(s)v_\pi(s)\)
推导梯度\(\nabla_\theta J=\mathbb{E}[\nabla_\theta \ln\pi(A|S,\theta)q_\pi(S,A)]\)
\(\theta_{k+1}=\theta_k+\alpha_k\nabla_\theta\ln\pi(a_t|s_t,\theta_k)q_k(s_t,a_t)\)
由于期望公式中包含以策略为分布的随机变量Action，因此该方法为On-policy。同时此处也包含随机变量S，与策略评估相同，也需要假设S分布。
DPG 同上 策略网络建立了State和Action之间的联系，之前采用分类网络输出每个Action的概率，非确定性策略。若为确定性策略，网络输出Action，Action与State为确定映射，不再为随机变量，梯度相应变化。
